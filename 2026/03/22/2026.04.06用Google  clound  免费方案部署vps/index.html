用Google clound 免费方案部署vps

免费政策：新人300美金的赠金（三个月）、使用免费层级（每月 1 个非抢占式 e2-micro 虚拟机实例、每月 30 GB 标准永久性磁盘、每月200g的出站流量，但不包括于cloundflare交互的流量）

流程：准备一个域名，托管到cloudflare，然后再Google clound中按要求创建一个VM实例，通过ssh连接进入Linux系统后，用yonggekkk的sing-box-yg项目，一键部署vps（sudo -i 、bash <(wget -qO- https://raw.githubusercontent.com/yonggekkk/sing-box-yg/main/sb.sh)）。期间，在Google clound的VM中添加DNS记录、允许HTTP和HTTPS协议，将防火墙出入站端口都开放，部署后就会生成五个协议的订阅节点，分别是：Vless-reality-vision、Vmess-ws(tls)/Argo、Hysteria-2、Tuic-v5、Anytls。

一、一句话总原理

它是在你的 VPS / Serv00 上，一键安装并启动一个 “加密流量转发服务”，把你的上网流量加密、伪装、转发到外网，实现安全翻墙。

二、完整流程（超简单）

  1. 你用客户端（手机 / 电脑）发出上网请求
  2. 请求被加密 + 伪装（看起来像普通上网，不是翻墙）
  3. 发到你的 VPS / Serv00 服务器
  4. 服务器上的 sing-box 程序接收、解密、识别你要访问的网站
  5. 服务器帮你去外网请求数据
  6. 数据原路加密返回给你

→ 最终效果：你看不到墙，墙看不到你

三、它到底干了哪 4 件事？（核心原理）

1. 安装核心程序：sing-box

这是一个现代化、高性能的代理核心，相当于 “翻墙发动机”。

脚本自动帮你装、自动配好，不用你手动改配置。

2. 同时开启多种翻墙协议（五协议 / 三协议）

  • VLESS Reality（最稳、最防封）
  • VMess + WS + TLS（最通用）
  • Hysteria2（超快）
  • Tuic-v5（超稳）
  • Anytls（抗封锁）

原理：多协议同时跑，一个被封换一个，保证永远能用。

3. 自动配置证书、端口、伪装

  • 自动生成 UUID / 密码
  • 自动配置 TLS 证书
  • 自动配置伪装路径
  • 自动生成可直接复制 / 扫描的节点

你不用懂技术，脚本全搞定。

4. 自动做分流、解锁、加速

  • 国内网站直连，国外走代理
  • 自动解锁 ChatGPT、X、YouTube
  • 支持 WARP 二次转发，IP 更干净
  • 支持 Argo 隧道，进一步防封

四、和之前 CF Workers 有什么区别？

方式 原理 优点 缺点
CF Workers 用 CF 免费服务器转发 免费、不用 VPS 速度一般、部分网站打不开
sing-box-yg 用你自己的 VPS转发 超快、超稳、全解锁 需要 VPS 或 Serv00

简单说：

  • CF 是免费公交车
  • sing-box-yg 是你自己的专车

五、最关键：为什么它不容易被封？

因为它用了这三层超强伪装：

  1. TLS 加密：看起来就是正常 HTTPS 网站
  2. WebSocket / Reality：没有任何翻墙特征
  3. 标准端口 443 / 80：和普通网站一模一样

防火墙检测：这是正常网站，放行！

实际内容：是你的翻墙流量。

六、终极极简总结

sing-box-yg = 一键帮你在服务器上搭建一个 “加密翻墙中转站”，

用多种高级协议 + 多层伪装，把你的流量安全送到国外，

速度快、稳定、防封、全解锁，而且全程自动化。

概念解释

这条命令是在Linux系统上一键下载并执行远程脚本，核心作用是自动安装sing-box代理工具。 — ### 逐段拆解 - bash：用bash解释器运行脚本 - <(...)：进程替换，把远程内容当成本地文件 。wget -qO-：静默下载，输出到标准输出 。后面网址：远程sb.sh脚本地址

DNS记录类型：

类型 全称 核心含义 通俗解释 适用场景
A Address Record 域名 → IPv4 地址 给域名绑定一个IPv4 服务器 IP，是最基础、最常用的记录 所有需要通过域名访问 IPv4 服务器的场景（网站、代理、VPS 等）
AAAA Quad-A Record 域名 → IPv6 地址 给域名绑定一个IPv6 服务器 IP 服务器支持 IPv6、需要面向 IPv6 用户访问时
CAA Certification Authority Authorization 限制证书颁发机构 指定哪些 CA 机构能给你的域名发 SSL 证书，防止恶意发证 提升域名安全，防止中间人攻击、证书滥用
CERT Certificate Record 存储证书 在 DNS 中存储域名的公钥证书 / 吊销列表，用于 DNSSEC 验证 现在极少使用，个人用户基本不需要
CNAME Canonical Name Record 域名 → 另一个域名 给域名起 “别名”，指向其他域名，不用重复绑定 IP 多个域名指向同一个服务器、简化子域名管理时
DNSKEY DNS Key Record 存储 DNSSEC 公钥 存储 DNSSEC 的加密公钥，用于验证 DNS 解析是否被篡改 开启 DNSSEC 时自动配置，个人用户不用手动加
DS Delegation Signer Record 委托签名记录 子域名 DNSSEC 的锚点，建立全球信任链，验证签名合法性 开启 DNSSEC 时由域名注册商配置，无需手动添加
HTTPS HTTPS Resource Record 优化 HTTPS 配置 在 DNS 中指定 HTTPS 服务的参数（ALPN、ECH 等），优化握手、隐藏流量特征 对 HTTPS 性能、抗审查有要求的服务（如代理、HTTPS 网站）

IP地址

0.0.0.0/0：表示所有 IP 地址（0.0.0.0 到 255.255.255.255）。

  • 原理：/0 表示子网掩码为 0.0.0.0，覆盖整个 IP 空间。
  • 常见用途：允许所有流量（防火墙白名单）或所有流量走代理（代理规则）。

192.168.2.0/24：表示局域网内的所有 IP（192.168.2.1 到 192.168.2.254）。

  • 原理：/24 表示前 24 位固定，最后 8 位可变，共 256 个地址。
  • 常见用途：放行内网流量（直连，不走代理）或限制仅内网可访问。

名称服务器

= DNS 服务器，负责 “把域名翻译成 IP 地址” 的服务器，就叫名称服务器（Name Server / NS 记录）

自签的证书和自有域名的证书区别

  • 自签证书 = 自己给自己发的身份证
  • 自有域名证书 = 权威机构（CA）给你发的身份证

浏览器只认权威机构发的，不认你自己发的。

==安全性方面==：

自签证书

  • 加密本身没问题（也是 HTTPS 加密）
  • 但无法防中间人攻击
  • 别人可以伪造一个同样的自签证书劫持你

正规证书

  • 加密 + 认证 + 防中间人
  • 无法伪造
  • 域名所有权被验证过

==有效期方面：==

自签证书

  • 想设多久设多久（10 年、20 年都行）

正规证书

  • 一般 90 天（Let’s Encrypt）
  • 但可以自动续签，不用管

uuid、TLS、WARP、serv00解释

1. UUID

简单说：就是你代理服务的 “专属账号 / 身份码”

  • 长得像一串随机字母数字：7b81f6ab-9a09-4e97-a28c-d25363aa6d27
  • 作用：只有带对这个 UUID 的客户端，才能连上你的 VPS 代理
  • 相当于：代理的用户名 + 密码二合一
  • 你链接里出现两次 UUID，是 TUIC 协议的格式要求，正常的
2. TLS

简单说：给网络流量 “加密 + 上锁” 的技术

  • 我们平时上网看到的小锁 HTTPS，用的就是 TLS

  • 作用：

    1. 流量加密，别人看不到你在访问什么
    2. 伪装成正常访问网站的流量，不容易被识别是代理

  • 你链接里的 sni、alpn、allowInsecure 都是 TLS 的配套设置

3. WARP

简单说：Cloudflare 出的一款免费 “网络加速 / 隐藏 IP 工具”

  • 可以单独当轻量 VPN 用

  • 也可以跟你的代理节点搭配使用，做中转、换 IP、防封、加速

  • 特点：免费、稳定、全球节点多

  • 很多人用 WARP 来：

    • 给 VPS 加速
    • 隐藏真实出口 IP
    • 配合节点提高稳定性
4. serv00

简单说：一个国外的【免费虚拟主机 / 免费小服务器】

  • 网址：serv00.com

  • 提供免费的小空间、小带宽、小内存

  • 很多人用它：

    • 搭建简易代理节点
    • 跑小脚本、做中转
    • 测试服务、临时用

  • 优点：完全免费

  • 缺点：资源少、限制多、容易被滥用封号

Cloudflare-vless-trojan 项目核心原理

这个项目的本质，就是把 Cloudflare 免费的 Workers/Pages 当成一台全球免费中转服务器，用来转发你的代理流量。

1. 整体流程（最核心）

  1. 你的设备 → 发送加密代理流量到 Cloudflare

  2. Cloudflare Workers/Pages（JS 脚本）接收并解析你的流量

  3. Cloudflare 帮你转发请求到目标网站

  4. 目标网站返回数据 → Cloudflare → 回到你的设备

    → 目标网站只看到 Cloudflare IP，看不到你的真实 IP

2. 流量伪装原理（为什么不被墙）

它把代理流量层层包装成正常网页流量：

  • VLESS/Trojan：给流量加密，防止被识别
  • WebSocket（WS）：伪装成网页聊天数据
  • TLS（HTTPS）：套上加密外壳，看起来就是正常访问网站
  • 端口 443/80：用最常见的网页端口，不触发拦截

3. Workers/Pages 为什么能做代理？

  • Cloudflare 允许免费运行 JS 代码
  • 代码功能：接收流量 → 转发 → 回传
  • 相当于一台免费、不限流量、全球节点的转发服务器

4. ProxyIP 是干嘛的？（关键）

  • 直接用 Workers 访问 CF 系网站（X、ChatGPT、CF 官网）会被拦截
  • ProxyIP = 第二台中转服务器
  • 路径变成：你 → CF Workers → ProxyIP → 目标网站
  • 作用：绕过 CF 自身的安全校验，正常打开这些网站

5. ECH / 分片 防封原理

  • ECH：加密域名信息，防火墙不知道你访问的域名
  • 分片：把数据包拆小，绕过流量特征检测
  • 目的：让防火墙无法识别这是代理流量

一句话终极总结

用 Cloudflare 免费服务器做中转，把代理流量伪装成正常 HTTPS 网页流量，配合加密与二次转发，实现稳定、免费、难被封锁的网络代理。
